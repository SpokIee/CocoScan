# Image assets

The Figma design uses real coconut photography that was **not** included with the
design hand-off. The files below are procedurally generated placeholders
(`node scripts/generate-placeholders.js`) with matching aspect ratios.

Replace each file with the Figma export using the **same file name** — no code
changes are needed.

| File | Used on | Figma reference | Recommended export |
| --- | --- | --- | --- |
| `welcome-bg.png` | Welcome, Login, Sign-up | Palm fronds + green coconuts, full-bleed | 1080×2220 JPG/PNG |
| `home-banner.png` | Home — "All About Coconut Diseases" banner | Green coconut on light background | 1080×600 PNG (transparent coconut ideal) |
| `coconut-tree.png` | Disease Information header | Coconut canopy with fruit | 1080×930 JPG |
| `about-bg.png` | Home — "About CocoScan" card | Dark leaf close-up | 1080×720 JPG |
| `camera-fallback.png` | Camera screen when no camera device exists | — | 1080×2220 |
| `light-leaf-bg.png` | Detecting / Result / Saved / History backgrounds | Soft white-to-green leaf wash | 1080×2220 PNG |

Icons come from `@expo/vector-icons` (Ionicons / MaterialCommunityIcons / Feather),
chosen to match the minimal line icons in the Figma frames.
